# Changelog

## [0.0.1] - 2026-05-02

### Added
- Initial pre-release of Tweakr
- Visual DOM editor — hover any element to inspect, edit text, or change styles
- Real-time CSS editing with live source file updates
- WebSocket bridge server bundled with the VS Code extension
- Chrome extension (currently under review in the Chrome Web Store)
- Auto-start server when a frontend project is detected
- Delete element with confirmation dialog
- Undo last action
- Angular support — bindings, events, directives, styleUrls
- Anonymous local-only usage analytics (never transmitted)

### Notes
- The Chrome extension is pending Chrome Web Store approval. The VS Code server is fully functional, but browser-side editing will not work until the Chrome extension is approved.
